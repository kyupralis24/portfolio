Financial Analytics with Python

Project Overview

This project implements a Bull Call Spread options trading strategy analysis for Reliance Industries using real-time market data from NSE India. It features the implementation of the Black-Scholes and Monte Carlo pricing models from first principles to evaluate the option strategy.

Python Numpy Scipy Pandas Matplotlib

Key Features

  • Real-time market data fetching from NSE CSV files
  • Implementation of the Black-Scholes option pricing model
  • Monte Carlo simulation for alternative option pricing
  • Validation of Put-Call Parity
  • Profit/Loss analysis and break-even point calculation
  • Generation of a visual payoff diagram for the strategy

Technical Implementation

The core of the project is a Python script that processes financial data and applies mathematical models to analyze an options trading strategy.

def black_scholes_call_put(S, K, T, r, sigma):
    d1 = (np.log(S/K) + (r + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2 = d1 - sigma * np.sqrt(T)
    
    call_price = S * norm.cdf(d1) - K * np.exp(-r * T) * norm.cdf(d2)
    put_price = K * np.exp(-r * T) * norm.cdf(-d2) - S * norm.cdf(-d1)
    
    return call_price, put_price

Strategy Analysis Results

The analysis for a Bull Call Spread on Reliance Industries (buying a call at ₹1300 and selling one at ₹1310) yielded the following results:

  • Break-even Point: ₹1305.60
  • Maximum Profit: ₹4.40
  • Maximum Loss: ₹5.60
