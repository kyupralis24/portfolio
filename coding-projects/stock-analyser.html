Stock Analyser

AI-Powered Stock Analysis and Portfolio Management Tool

Project Overview

This project is an advanced stock analysis tool that leverages machine learning to provide deep insights into stock performance and portfolio health. It features an LSTM model for price prediction, a DNN for portfolio health scoring, and a Flask-based API to serve the analysis to a real-time dashboard.

TensorFlow Python Flask Scikit-learn Pandas yfinance NLTK

Key Features

  • LSTM-based stock price prediction
  • DNN model for portfolio health scoring
  • Real-time data fetching with yfinance
  • Sentiment analysis of financial news using NLTK
  • Flask API for serving data to the frontend
  • Comprehensive risk assessment and scenario analysis
  • Automated trading recommendations

Dashboard Analysis

The project features a real-time dashboard that visualizes the analysis performed by the Python backend. Below are screenshots of the main components and an explanation of how the metrics are calculated.

Portfolio Overview

This section provides a high-level overview of the portfolio's health and composition.

  • Portfolio Performance: A historical chart of the total portfolio value, tracked daily.
  • Portfolio Health: A score generated by a Deep Neural Network (DNN) that takes overall performance, volatility, and sector concentration as inputs to provide a single health metric from 0-100.
  • Risk Level: Assessed based on portfolio volatility and concentration in any single sector.
  • Diversification Score: Calculated by measuring the deviation of sector allocations from an ideally balanced portfolio. A higher score indicates better diversification.
  • Sector Exposure: A percentage breakdown of the portfolio's value by industry sector.

Individual Stock Analysis

Each stock in the portfolio is analyzed individually to provide granular insights and predictions.

  • Predicted Price: The future stock price is predicted using a Long Short-Term Memory (LSTM) neural network trained on historical price data.
  • Potential Upside/Downside: This is the percentage difference between the LSTM model's predicted price and the current market price, indicating potential short-term movement.
  • Value: The total current market value of the holding for that stock.

Technical Implementation

The project combines data fetching, model training, and a web server to deliver a complete stock analysis solution.

# Build and Train LSTM Model
def build_lstm_model(time_steps):
    model = tf.keras.Sequential([
        tf.keras.layers.LSTM(64, return_sequences=True, input_shape=(time_steps, 1)),
        tf.keras.layers.LSTM(32),
        tf.keras.layers.Dense(1)
    ])
    model.compile(optimizer='adam', loss='mse')
    return model
